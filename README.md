# FXTRADE Smart Digital Terminal v29

Sandbox account and server-wallet architecture.

## Added
- Account registration and sign-in
- Server-side sandbox wallet API
- Sandbox deposit/withdrawal requests
- Transaction ledger
- Basic verification details
- Existing simulated trading dashboard and history

## Important
This version does **not** accept real customer funds, connect to M-Pesa/banks/cards, or execute real-money trades. The server wallet is an architecture prototype. For production, use a persistent database, secure session/authentication infrastructure, an authorized payment provider, KYC/AML controls, audit logs, licensing/compliance review, and a legitimate execution/settlement source.
